# 官方能力包

编辑器里的可选能力（物理、以后的导航、后期以外的玩法模块）按能力包接，不做成谁都能塞包进来的插件宿主。

## 开关

开关记在工程里，字段是 `project.t3d` 文档的 `capabilities`。入口是菜单 **文件 → 工程设置**。不放进编辑器的全局设置。换一台机器打开同一份工程，启用的能力和检查器一致。

场景属性里只保留该项自己的场景参数（例如物理的重力），不再承担能力包的总开关。

新建工程使用每项的默认值。物理默认开。

关掉一项时，节点上已经填过的数据留着，只停止加载对应的库，并收起这项的检查器卡片。重新打开后照原样模拟。

## 目录

每个能力包是 `src/capabilities/<id>/` 下的一个目录，自己带三样东西：

- 写进场景节点或场景设置的普通数据
- 检查器卡片
- 库的实现

编辑器其余部分只问「这项开着吗」，并调用该包自己的接口。库的类型不进场景文档，也不进视口的其他文件。

没有统一的生命周期基类。物理、导航、后期挂进编辑器的位置不一样，共用一份开关清单就够了。清单在 `src/capabilities/registry.ts`。

加载用动态 `import()`。没开的能力不进内存。现在不从外部下载安装包。哪一项以后大到不该随安装包一起发，只改那一项的加载入口。

## 物理

物理包在 `src/capabilities/physics/`。场景节点用 `physics` 字段描述碰撞体和刚体。场景重力在画面设置的 `gravity` 上。

`PhysicsWorld` 是包内的接口：同步刚体、按固定步长推进、读回动态物体的位姿。试玩循环只依赖这个接口。`RapierWorld` 是目前唯一的实现，也是唯一引用 `@dimforge/rapier3d-compat` 的文件。换物理库只换这个实现。

这一版做 GM3D 里刚体和碰撞体那一层：

- 盒子、球体、胶囊，尺寸跟着世界缩放
- 静态、动态、运动学
- 触发器
- 质量、摩擦、弹性、线阻尼、角阻尼、重力缩放
- 场景重力
- 试玩时画碰撞线框，停止试玩后不留在画面里

还没有接上、但仍然属于这一个物理包、而不是新能力包的部分：角色控制器、碰撞层和矩阵、网格碰撞体、碰撞和触发事件。它们以后加在 `PhysicsWorld` 上。

试玩中的位姿写回节点，停止试玩时用试玩前的快照恢复。物理步进不记入撤销。

## 导航

导航包在 `src/capabilities/navigation/`。默认开启。场景画面上的 `navigation` 字段保存烘焙参数：格子、坡度、代理尺寸、障碍容量。节点上的 `navigation` 表示这块几何是静态表面，还是试玩时挖开网格的竖直圆柱障碍。关掉能力包后这些数据留着，检查器收起，并且不再加载 Recast。

`NavigationWorld` 是包内的接口：烘焙、还原、同步障碍、查询路径、取出调试网格。`recastNav.ts` 和烘焙用的 `bake.worker.ts` 是仅有的引用 `recast-navigation` 的文件。烘焙在 Worker 里进行，取消会终止这次 Worker。障碍容量为 0 时得到静态网格；大于 0 时得到可以被障碍挖开的 Tile Cache。

烘焙结果按场景记在工程文档的 `navMeshes` 里，不进撤销。视口里的可行走面是编辑器辅助物，隐藏辅助物时一起隐藏，试玩时仍可看见。角色沿网格移动还不在这个包里；寻路调用 `findNavigationPath`。

## 特效

特效包在 `src/capabilities/particles/`。默认关闭。资源和物体上的数据、材质引用、和 `three.quarks` 的版本隔离见 `docs/particles.md`。

## 界面

界面不是能力包，没有开关。运行时和编辑器始终在。领域包可以自带界面文档；关掉领域包时，只收起那个包的文档。文档、编辑器和阶段见 `docs/ui.md`。

## 标签和层

标签和层是工程目录，不是可关闭的能力包。数据在 `project.t3d` 里，入口是 **文件 → 标签**、**文件 → 层**，工程设置里也有同样的管理按钮。

标签表与 Unity Tag 相同：每个物体一个主标签，另可加多条层级标签（如 `Team.Enemy`）。内置 `MainCamera`。删掉标签时，仍引用它的物体会被清掉。层级面板可以按标签筛选。

层用 0 到 30 的位。`Default` 占第 0 位且不能删。第 31 位留给编辑器手柄和网格。眼睛图标控制该层在视口里是否可见，并影响点选。物理碰撞矩阵是对称的：勾上表示这两层相撞，关掉则所有层都相撞。矩阵会写进 Rapier 的 16 位碰撞组，所以只有前 16 个层位参与过滤。
